\section{Introduction}
FFXIV Character Search is a browser-based application that allows users to search and view character information from Final Fantasy XIV's Lodestone. This guide focuses on deploying and running the application using GitHub Pages.

\section{Project Structure}
\begin{lstlisting}

├── app.js
└── docs/
    └── USER_GUIDE.tex
\end{lstlisting}

\section{Local Development}

\subsection{Prerequisites}
\begin{itemize}
    \item A modern web browser (Chrome, Firefox, Safari, or Edge)
    \item Git (for version control)
    \item A text editor (VS Code, Sublime Text, etc.)
\end{itemize}

\subsection{Running Locally}
1. Clone the repository:
\begin{lstlisting}[language=bash]
git clone https://github.com/username/ffxiv-character-search.git
cd ffxiv-character-search
\end{lstlisting}

2. Open index.html in your browser:
\begin{itemize}
    \item Double-click index.html, or
    \item Use a local server:
    \begin{lstlisting}[language=bash]
# Python 3
python -m http.server

# Python 2
python -m SimpleHTTPServer
    \end{lstlisting}
\end{itemize}

\section{GitHub Pages Deployment}

\subsection{Initial Setup}
1. Create a new GitHub repository:
\begin{itemize}
    \item Go to github.com
    \item Click "New repository"
    \item Name it "ffxiv-character-search"
    \item Make it public
    \item Don't initialize with any files
\end{itemize}

2. Push your code:
\begin{lstlisting}[language=bash]
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/username/ffxiv-character-search.git
git push -u origin main
\end{lstlisting}

\subsection{Enable GitHub Pages}
1. Go to your repository's Settings
2. Navigate to Pages section
3. Under "Source":
   \begin{itemize}
       \item Branch: main
       \item Folder: / (root)
   \end{itemize}
4. Click Save

Your site will be available at:\\
\url{https://username.github.io/ffxiv-character-search}

\section{Using the Application}

\subsection{Searching for Characters}
1. Enter a character name (required)
2. Optionally specify:
   \begin{itemize}
       \item World name
       \item Data Center name
   \end{itemize}
3. Click Search
4. Results will appear below

\subsection{Viewing Character Details}
1. Click "View Details" on a character card
2. The details panel will show:
   \begin{itemize}
       \item Character portrait and info
       \item Combat jobs (Tanks, Healers, DPS)
       \item Crafting and Gathering jobs
   \end{itemize}

\section{Troubleshooting}

\subsection{Common Issues}
\begin{itemize}
    \item If character search fails:
        \begin{itemize}
            \item Check your internet connection
            \item Verify Lodestone is accessible
            \item Try refreshing the page
        \end{itemize}
    \item If images don't load:
        \begin{itemize}
            \item Check if Lodestone is blocking requests
            \item Try a different browser
        \end{itemize}
    \item If GitHub Pages isn't working:
        \begin{itemize}
            \item Ensure repository is public
            \item Check if GitHub Pages is enabled
            \item Verify the correct branch is selected
        \end{itemize}
\end{itemize}

\section{Browser Support}
The application works best in:
\begin{itemize}

\end{itemize}

\section{Technical Notes}
\begin{itemize}
    \item Uses vanilla JavaScript (no frameworks)
    \item Directly parses Lodestone HTML
    \item Uses CSS Grid for responsive layouts
    \item Implements iframe-based CORS workaround
\end{itemize}
